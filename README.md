# Canadian Occupational Prestige — Statistical Analysis (1971)

A university statistics project analyzing **102 occupations in Canada (1971)** using **IBM SPSS**. The analysis explores relationships between occupational prestige, education, income, occupation type, and women's representation in the occupation.

## Methods

- Descriptive statistics and scatterplots
- Simple linear regression and multiple linear regression
- Hypothesis testing, p-values, and confidence intervals
- Model comparison using R² and adjusted R²
- Residual diagnostics and multicollinearity checks (VIF)
- Two-factor ANOVA

## Selected findings

- Education and income were both positively associated with occupational prestige in the sample.
- The multiple linear regression model using education and income explained **79.8% of the observed variation in occupational prestige (R² = 0.798)**, compared with 72.3% for education alone and 51.1% for income alone.
- Occupational income differed across occupation categories and groups defined by women's representation. These are **occupational-level associations**, not evidence of individual pay discrimination or causal effects.
